E-Filing Portal

Schedule-by-Schedule Filing Guide

How TaxSarthi navigates the official incometax.gov.in portal alongside you

1. Schedule Salary (Form 16 Part B) ITR-1 / ITR-2
Transcribe Gross Salary (s.17(1)), Perquisites (s.17(2)), and Standard Deduction (₹75k New / ₹50k Old). Professional tax is entered under s.16(iii).
2. Schedule Capital Gains (Schedule CG) ITR-2 / ITR-3
Section 111A equity STCG @ 20% and Section 112A equity LTCG @ 12.5% with the aggregate ₹1,25,000 statutory exemption applied automatically.
3. Schedule VI-A Deductions & Taxes Paid (Schedule TDS) All Forms
Cross-check claimed TDS against 26AS TAN entries and AIS totals to prevent automated intimation mismatches u/s 143(1).
4. Part B-TTI & Final Verification The 3 Final Acts
Match the portal's computed tax to TaxSarthi's output to the exact rupee. You alone perform the final three actions: Pay, Submit, and e-Verify.
Integration

Install TaxSarthi Across Any Platform

Run as a CLI tool or plug into Antigravity, Claude Code, or OpenAI Codex

📦 Universal Installer

Clone and review locally, then install into your preferred agent without touching the network:

git clone https://github.com/karanb192/itr-wala.git
cd itr-wala && ./install.sh all

🤖 Claude Code Plugin

Install TaxSarthi directly as a native Claude Code plugin:

/plugin marketplace add karanb192/itr-wala
/plugin install taxsarthi@taxsarthi

🐍 Python CLI Tool

Install and run the high-performance command line package:

pip install -e .
taxsarthi compute income.json
